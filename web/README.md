# Teaching site

Next.js App Router site for RevX Paper Desk. Portuguese first, with a site-wide English toggle.

```bash
npm install
npm run dev    # http://127.0.0.1:43123
npm run build
```

Deploy on Vercel with the framework preset **Next.js**, root directory **`web`**, install command `npm install`, and build command `npm run build`. No environment variables are required. Output is the default Next.js build (not a static export).

The pages use a frozen paper sample. They do not proxy a private dashboard and they do not place orders.
